## 1. 시작 문장 붙여넣기

새 대화를 열 때마다 맨 처음에 한 번. **내용은 몰라도 됩니다.**

```
본로이 ERP 작업이야. 나는 개발을 전혀 몰라.

- CLAUDE.md, docs/PROJECT_CONTEXT.md, docs/AI_USAGE_GUIDE.md 를 먼저 읽어줘.
- 항상 쉬운 말로, 화면에서 뭐가 달라지는지로 설명해줘.
- 데이터 수정·삭제, 돈 계산(마진·부가세) 변경처럼 되돌리기 어려운 일은
  하기 전에 반드시 나한테 먼저 물어봐.
- 나한테 물어볼 땐 선택지를 A/B 두 개로 좁히고, 네 추천도 같이 말해줘.
- 다 끝나면 이 세 가지만 알려줘.
  ① 뭐가 바뀌었는지 한 줄  ② 내가 화면에서 확인할 것 3개  ③ 언제 화면에 보이는지
```

### 이 문장이 대신 해주는 일
- **위험한 건 먼저 물어보게** 만듭니다 → 당신이 "이거 위험한가?"를 판단할 필요가 없습니다.
- **쉬운 말로 답하게** 만듭니다 → 못 알아들을 말이 줄어듭니다.
- **확인할 것 3개를 알려주게** 만듭니다 → 뭘 봐야 할지 고민할 필요가 없습니다.

---

## 2. 그냥 말하면 됩니다

화면 캡처를 붙이고 한 줄. 이게 전부입니다.

> 📱 (화면 캡처) **"여기 표가 너무 빽빽해서 한눈에 안 들어와"**
>
> → Claude: "거래처별로 묶어서 색을 넣을까요(A), 글자를 키우고 줄 간격을 넓힐까요(B)? **A를 추천합니다.**"
>
> → **"A로 해줘"**

답이 안 떠오르면 **"네가 추천하는 걸로 해줘"** 한 마디면 됩니다. 그게 정답일 때가 많습니다.

### 잘 안 통할 때만 — 네 줄로 쪼개기
같은 걸 두세 번 말했는데도 엉뚱하게 나오면, 그때만 이렇게.

```
어디서   : 주문 내역 화면에서
지금     : 거래처 색이 다 비슷해서 구분이 안 돼
원하는것 : 거래처마다 확실히 다른 색으로 해줘
왜       : 눈으로 빨리 찾으려고
```
네 줄을 그냥 이어 붙이면 그대로 좋은 요청이 됩니다.

💡 **조건은 한 번에 다 말하는 게 이득입니다.** 9월에 마진 표시 하나를 두고 네 번 왔다 갔다 한 적이 있는데, 한 번 오갈 때마다 화면 반영이 하루씩 밀렸습니다.

---

## 3. 확인은 3개만

시작 문장을 넣었다면 Claude가 "확인할 것 3개"를 알려줍니다. 그것만 눌러보면 됩니다.

- [ ] 오후 3시 지났나 → 안 지났으면 **그냥 기다린다**
- [ ] 화면 새로고침 (`Ctrl + Shift + R`)
- [ ] Claude가 알려준 **3개**를 눌러본다
- [ ] **숫자가 바뀐 거라면** 실제 1건만 손으로 계산해 맞춰본다

복붙: `내가 화면에서 확인할 것 3개만 알려줘.` / `방금 배포된 거 문제 있어. 되돌려줘.`

⚠️ **숫자만큼은 사람이 봐야 합니다.** 기계 검사는 "글자가 틀렸나"만 보지 "금액이 맞나"는 못 봅니다.

| 기계가 잡아주는 것 | 사람만 아는 것 |
|---|---|
| 문법이 틀렸다 | 숫자가 실제로 맞는가 (마진·부가세) |
| 빌드가 안 된다 | 화면에서 진짜 눌리는가 |
| 타입이 안 맞는다 | 보기 편한가 / 업무 흐름에 맞는가 |
| ↑ 여기까지가 "빌드 통과"의 뜻 | ↑ 이건 당신 몫 |

## "다 됐다는데 화면이 그대로예요"

고장이 아닙니다. 화면은 **하루에 한 번**만 바뀝니다.

```
 1. 당신이 요청
      ↓
 2. Claude가 코드를 고침 (기계 검사 통과해야 다음으로)
      ↓
 3. 작업대(브랜치)에 저장          ← 원본은 아직 그대로
      ↓
 4. 결재(PR) → 원본(main)에 합침   ← 여기까지 와도 화면은 안 바뀜
      ↓
 ⛔ 매일 오후 3시 — 배포 관문 (하루에 한 번만 열린다)
      ↓
 5. 직원들 화면에 반영              ← 이제야 눈에 보인다
```

"다 됐다는데 화면이 그대로"는 **3번·4번에 머물러 있다는 뜻**입니다.

**급할 때**: Claude에게 **"지금 바로 배포해줘"** 라고 하면 됩니다. 몇 분이면 반영됩니다. 직접 하실 필요 없습니다.

## Claude가 물어보면

| Claude가 이러면 | 이렇게 답하세요 |
|---|---|
| "A로 할까요, B로 할까요?" | `네가 추천하는 걸로 해줘. 왜 그런지 한 줄만.` |
| "이건 데이터를 고칩니다. 진행할까요?" | `잠깐. 대표님 확인받고 할게. 뭐가 어떻게 바뀌는지, 잘못되면 되돌릴 수 있는지 3줄로 정리해줘.` |
| "다 했습니다" | `내가 화면에서 확인할 것 3개만 알려줘.` |
| "이건 확인 못 했습니다" | `그럼 내가 뭘 확인해주면 돼?` (솔직하게 말해주는 것 — 좋은 신호입니다) |
| 엉뚱한 걸 하고 있을 때 | `잠깐 멈춰. 그건 내가 원한 게 아니야. 지금까지 한 거 되돌리고 다시 하자.` |

## 어디서 멈춰야 하나

**외우지 않아도 됩니다.** 시작 문장을 넣었다면 Claude가 먼저 물어봅니다. 물어보면 아래 색만 보세요.

| | 무엇 | 어떻게 |
|---|---|---|
| 🟢 | 글자·색·크기·정렬, 버튼 위치, 안내 문구, 오타, 필터 추가 | 그냥 진행 |
| 🟡 | 화면 구조·메뉴 바꾸기·없애기 | 한 번 확인하고 |
| 🔴 | **돈 계산 규칙(마진·부가세·청구액), 데이터 수정·삭제·합치기** | **대표 확인 필수** |

🔴는 되돌리려면 DB를 다시 손대야 합니다.

## 자주 있는 일

| 상황 | 이렇게 |
|---|---|
| 화면이 안 바뀌었어요 | 오후 3시 전이면 정상. 지났으면 `Ctrl+Shift+R`. 그래도면 → `배포됐는지 확인해줘` |
| 숫자가 이상해요 | **실제 건 하나를 그대로** 알려주면 됩니다. 예: "9/8 강남 주사기 건, 마진이 −3,000으로 나와. 매입 10,000 납품 12,000인데." |
| 에러가 떴어요 / 화면이 하얘요 | 캡처 + "뭘 누르다가 이랬어" 한 줄 |
| 직원 개선 요청을 보고 싶어요 | `개선 요청(feedback)으로 들어온 것들 정리해서 보여줘.` |
| 대화가 길어져서 느려요 | 새 대화 + 시작 문장 다시 붙여넣기 |
| 이거 물어봐도 되나 싶어요 | **다 물어봐도 됩니다.** "왜 이래?", "쉬운 말로 다시" 전부 정상 질문 |

## 가끔 나오는 말 (몰라도 지장 없음)

| 이런 말이 나오면 | 이런 뜻입니다 |
|---|---|
| "UI 테스트 못 함" | 화면을 직접 눌러보진 못했다 → **당신이 눌러봐야 함** |
| "빌드 통과" | 글자·문법은 이상 없다 → **금액이 맞다는 뜻은 아님** |
| "확인 못 함" | 확실하지 않다 → 사실로 받아들이지 말 것 |
| "마이그레이션 적용" | **데이터 창고를 실제로 바꿨다** → 숫자 확인 필요 |
| "~인 것 같습니다" | 확신이 없다 → "확실해?" 되물으세요 |
| 배포 | 직원들 화면에 반영하는 것 (매일 오후 3시) |
| main | 진짜로 쓰이는 원본 |
| PR | "원본에 합쳐도 될까요?" 결재 요청서 |
| 롤백 | 되돌리기 |

## 한 장 요약 (프린트해서 붙여두기)

```
① 새 대화      = 시작 문장 붙여넣기
② 요청         = 캡처 + 한 줄
③ 물어보면     = "네가 추천하는 걸로"
④ 빨간 경고    = "대표님 확인받고 할게"
⑤ 확인         = 오후 3시 이후, Claude가 준 3개
⑥ 숫자 바뀌면  = 실제 1건 손으로 대조
⑦ 이상하면     = "되돌려줘"
⑧ 모르면       = 그냥 물어본다
```

## 담당자 인수인계 메모

- 이 ERP는 **로그인 없이** 씁니다. 새 DB 테이블을 만들면 접근 권한을 같이 줘야 화면이 안 깨집니다. Claude가 알아서 하지만, DB를 건드렸다면 한 번 물어보세요: `anon 권한도 같이 줬어?`
- **진짜 데이터는 라이브 DB에 있습니다.** 코드에 적힌 설명보다 실제 DB가 우선입니다.
- 요즘은 작은 화면 수정을 main에 바로 저장합니다. **DB·데이터·돈 계산을 건드리는 작업은 PR로 남겨달라고 하세요.** → `이건 바로 main에 넣지 말고 PR로 만들어줘.`
